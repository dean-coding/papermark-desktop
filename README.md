## 密印文档 (Papermark)

### Overview

密印文档是一款隐私优先的文档加印工具。文件默认在浏览器本地处理，不上传服务器、不落盘存储。核心场景：身份证复印件加水印防冒用、PDF/Word/代码文件加斜向水印防外传、重要文件加密+水印双保险。支持 Markdown/DOCX/代码/图片转 PDF，提供 Web 版和桌面端（Mac/Windows）。

### Products & Services

- 身份证加印：给身份证复印件加"仅限办理XX"斜向水印，防止被冒用 → /idcard
- PDF加水印：给 PDF、Word、Markdown、代码文件加斜向水印防外传 → /watermark
- 文件加密+水印：给重要文件加水印并设置打开密码，双保险防泄露 → /encrypt
- 代码转PDF：20+编程语言语法高亮，加水印导出 PDF → /code
- Markdown转PDF：GFM语法+数学公式+代码高亮，加水印导出精美 PDF → /markdown

### Key Differentiators

- 100% 本地处理：文件不离开用户设备，不上传服务器，不落盘存储
- 场景化设计：每个场景解决一个具体痛点，不是通用工具堆砌
- 水印+加密组合：一站式完成"加注+防护"，无需分别操作
- 按次付费：用多少付多少，次数永不过期，不做订阅制
- 全平台：Web 即开即用 + 桌面端离线可用
